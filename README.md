# yuyaappdevelopp-star.github.io

App Store のサポート／マーケティング用サイトです。

**ルート (`/` / `index.html`) は「動画を容量順に整理・削除」専用です。差し替えないでください。** そのアプリの公開URLがルートのままです。

新しいアプリはフォルダを追加します。既存アプリのURLは変えないこと。

| Path | App |
| --- | --- |
| `/` | 動画を容量順に整理・削除 |
| `/background-remover/` | Remove Photo Background |
| `/snowvs/` | SnowVS |
| `/dopagaki/` | Dopagaki |
| `/mosquito-vs-human/` | 蚊vs人間 / Bite or Slap: Mosquito Duel |
| `/apps/com-groocon-videoaudio/` | 動画の音声を保存 / Video to MP3 - Save Audio |
| `/apps/com-groocon-slowvideo/` | 動画をスローにする / Slow Down Video |
